# データポリシー

## 公開リポジトリに含めるもの

- アプリケーションコード
- DBスキーマと架空サンプル
- 汎用的なクローラー／インポート処理
- プレースホルダーだけを含む設定テンプレート

## 公開リポジトリに含めないもの

- 実在大学のPDF、画像、OCR結果、問題文、解答、解説
- PDFから作成したレビュー、ページ範囲、インポートSQL
- パスワードハッシュ、セッショントークン、学習履歴
- CloudflareアカウントID、D1 ID、個人メール、本番ドメイン
- アクセス制限を伴う資料の取得情報

`data/crawl/`、`data/agent-review/`、`data/open-inshi/` はローカルまたは非公開ストレージ専用です。これらのパスは `.gitignore` と公開前チェックの両方で保護します。

## 個人分析とモデル評価

個人分析は、本番D1にある本人の解答結果、所要時間、自信度、ヒント・解答参照、つまずき、概念別習熟度から生成します。API応答は本人の認証済みセッションに限定し、`Cache-Control: private, no-store` を付けます。

定着・自力再現・時間配分の診断は、本人の記録だけを条件別に比較し、他ユーザーとの順位や偏差値を作りません。同一問題の再挑戦は1〜30日の間隔を空けた3組以上、補助の有無と時間内外の比較は各3件以上になるまで差分を表示しません。問題難度や形式の差を完全には調整できないため、合否予測や能力診断ではなく次の演習条件を選ぶ参考値として表示します。

推薦精度を検証するため、推薦を表示した時点のユーザーID、問題ID、推薦モード、モデル版、個人化予測値、単純ベースライン予測値、推定信頼度、日時を保存します。問題文、解答メモ、メールアドレス、チャット内容は評価ログへ複製しません。推薦後に同じ問題を解いた場合は、直近30日以内の最新予測1件だけへ観測達成度を結び付けます。

単純ベースラインと候補モデルは表示順位を変えないシャドー比較に限定します。候補は現行予測と同じ推薦表示・解答結果へ結び付け、低品質な実験群を利用者へ配信しません。モデル監視画面は reviewer / admin だけが利用でき、個別ユーザーや自由記述を返さず集約値だけを表示します。全体判定と候補比較は観測50件以上かつ5ユーザー以上で開始し、セグメントは観測20件以上かつ5ユーザー以上を満たさない限り非表示にします。

推薦の行動有効性には表示順位と推薦スコアを保存します。未観測期間の短い表示を失敗扱いしないよう、7日経過した表示だけを7日以内演習率の対象にします。全体指標は100表示・10ユーザー以上、順位帯の指標は50表示・5ユーザー以上になるまで非表示にします。

個人分析が提示する学習戦略は、表示時点の推奨モード、根拠、信頼度と直前3問の平均達成度を保存します。本人が明示的に採用した戦略だけを検証対象とし、採用後に同じ推薦モードから表示されて解答された最初の3問を比較します。同時に有効な戦略は1件に限定し、新しい戦略を採用した場合は未完了の旧戦略を中止します。問題文、解答メモ、メールアドレス、自由入力は戦略検証ログへ保存しません。

管理画面の個人戦略効果は、完了30件・10ユーザー以上になるまで全体効果量を表示しません。推薦モード別の効果量は10件・5ユーザー以上になるまで非表示にします。この比較はランダム化比較試験ではなく本人内の前後比較であり、問題難度、時期、学習時間などの交絡が残るため、因果効果ではなく次の仮説を選ぶ運用指標として扱います。

目標準備度は、本人が設定した目標日・週あたり学習日数、目標の学習グラフに紐づく分野の保守的習熟度、直近28日間の計画実施状況と学習日数から算出します。合否確率、大学間順位、他ユーザーとの比較には使いません。証拠が3件以上ある対象分野が30%未満の場合は優劣を判定せず「証拠を収集中」と表示し、推定値には現在の保守値から生の習熟推定までの幅を併記します。

計画遵守率は問題数ではなく予定した学習日単位で算出します。同日に複数問題がある場合も1日として扱い、その日の全項目を完了したときに完了日とします。計画再生成時は当日以降の未成熟な予定だけを置き換え、過去の未完了日は再計画済み履歴として保持するため、再生成だけで遵守率を上げることはできません。この履歴は180日で削除し、準備度計算には直近28日だけを使います。

本人が準備度の変化を確認できるよう、目標ID、モデル版、日付、準備度と推定幅、証拠充足率、計画遵守率、週あたり学習日数を日次で1件保存します。集計定義が異なるモデル版は混在させず、現在の準備度v2だけを運営評価へ使用します。目標文、志望理由、解答メモ、メールアドレス、問題文は準備度スナップショットへ複製しません。目標の削除時は関連スナップショットも削除します。

準備度モデルの運営評価では、日次スナップショットをユーザー・目標ごとに週1点へ間引き、21〜35日後のうち28日に最も近い目標分野習熟度と照合します。複合準備度の誤差は、現在の目標分野習熟度をそのまま予測値にする基準モデルと比較します。全体誤差は50組・10ユーザー以上、準備度帯は20組・5ユーザー以上になるまで非表示にします。

計画遵守率と28日後の習熟度変化は、高遵守・低遵守の双方が30組・10ユーザー以上になるまで差を表示しません。この差には学習意欲、可処分時間、目標難度などの交絡が残るため、計画実施の因果効果とは表現せず、関連仮説の選択にだけ使います。管理画面には個別ユーザーID、目標名、志望先を返しません。

予定した学習日が4日以上あり、計画遵守率が60%未満、直近4週間の学習日数が目標の70%未満の場合、週の総学習時間を減らさず少ない曜日へまとめる再配分を提案します。目標や計画は本人が明示的に採用するまで変更しません。採用時の予定日数・学習時間・遵守率と、採用後14日間の予定日完了率を保存し、30件・10ユーザー以上になるまで管理画面の効果量を非表示にします。検証中に本人が目標や日程を手動変更した場合は比較を中止します。これは本人内の前後比較であり、曜日再配分の因果効果とは表現しません。個別ユーザー、目標名、志望先、解答内容は管理集計へ返しません。

重点学習の候補は、未観測分野を弱点とみなさず、証拠が2件以上ある低習熟分野または復習期限を迎えた分野だけから選びます。本人が明示的に採用した場合も、重点分野は2週間の予定の最大50%に制限し、残りは分散学習へ割り当てます。採用前と14日後の保守的習熟度・予定日完了率・範囲カバー率を保存し、検証終了後は自動で分散計画へ戻します。管理画面では完了30件・10ユーザー以上になるまで効果量を非表示にし、習熟度が上がっても計画遵守や範囲カバーを損なう案は支持しません。この比較もランダム化比較ではなく、因果効果とは表現しません。

未観測分野の確認枠は、本人が演習できる問題が存在する分野に限って提示し、2週間の予定の最大20%だけを前倒しします。未観測は弱点とみなさず、本人が明示的に採用した後、最初の実測証拠を得た時点で確認枠を終了して分散計画へ戻します。14日以内の情報獲得有無・取得時間・予定日完了率・範囲カバー率を保存し、管理画面では完了30件・10ユーザー以上になるまで集約値を非表示にします。これは確認枠の行動有効性を評価する指標であり、習熟への因果効果とは扱いません。

確認枠で提示する問題は、対象ノード内で直接測れる未観測概念数、承認済み知識エッジの重みと信頼度、難度、目安時間から情報効率の代理スコアを算出し、1回の確認日につき1問だけ選びます。同時に従来順位の先頭候補と双方の代理スコアを保存し、本人が解答した場合だけ直接証拠数・対象内証拠増加・所要時間・着手までの時間を結合します。問題文、解答メモ、メールアドレスは評価ログへ複製しません。管理画面は14日経過した30提示・10ユーザー以上のみを集約し、問題選定の因果効果とは表現しません。

ランキングの適用可能性は、従来順位で演習可能な候補数、代理スコアを計算できた候補数、候補間の効用差、実際に先頭候補を変更したかを保存して評価します。比較可能な候補が2問未満、または最高候補と最低候補の代理スコア差が2ポイント未満の場合は、ランキング効果を比較できない提示として従来候補を維持します。管理画面の比較機会率・選定変更率・代理効用差は14日経過した30提示・10ユーザー以上になるまで非表示にします。比較機会率50%は候補整備の暫定運用基準であり、学習効果やランキングの因果効果を示す値ではありません。

診断コンテンツの充足度は、アクティブな学習グラフの全ノードを対象に、レビュー済み問題、有効な公開元、承認済み`tests`エッジ、アクティブな概念マッピングをすべて満たす異なる問題数で監査します。`requires`だけの関連、非公開・出典停止中・未レビューの問題は直接測定問題へ数えません。1ノード2問以上を診断準備済みとし、全ノードの80%以上を満たすことを暫定運用基準にします。未マッピング、0問、1問のノードは運営画面で分けて表示し、前提・基礎ノードと下流影響の大きいノードから補完します。この集計はコンテンツメタデータだけを使い、個人の学習履歴や自由入力を含みません。

問題名と学習ノード名の文字列一致だけでは、概念が正しい問題を除外したり、名称だけ似た問題を過大評価したりするため、診断用途の明示リンクを別に管理します。編集者が候補化できるのは、アクティブな学習ノードと、レビュー済み・公開元有効な問題の間に承認済み`tests`概念の重複がある場合だけです。候補化した時点では学習計画や充足率を変更せず、reviewer / admin が再検証して承認した`direct`リンクだけを利用します。承認時は候補状態を楽観ロックし、作成・承認・却下を監査ログへ残します。明示リンクは問題文、解答、個人学習履歴を複製しません。

既存問題を流用できないノードでは、問題本文を生成する前にオリジナル診断問題の仕様を作成します。仕様は測定目的、観測する証拠、認知負荷、解答形式、難度、所要時間、重み合計100%の採点基準、想定誤答を構造化し、`original_only`を必須とします。問題制作へ進めるには、品質契約を満たす承認済み仕様を2件以上、かつ異なる認知負荷で確保します。提出者とは異なるreviewer / adminが、対象ノードとの一致、採点可能性、第三者問題の非複製を個別に確認します。版番号による楽観ロックと監査ログを保持し、却下時は修正理由を必須にします。仕様の承認だけでは診断問題数や推薦候補へ加算しません。

承認仕様から制作するオリジナル問題は、問題本文、模範解答、解説・検算、満点・部分点・誤答の答案例、採点基準ごとの得点、曖昧性・答え漏洩・誤概念識別の耐性チェック、原創性メモを必須にします。答案例の総得点は承認仕様の重み付き採点結果と一致させ、完全一致する問題内容は指紋で重複提出を拒否します。作成者・提出者とは異なるreviewer / adminが、仕様との一致、解答の正しさ、採点較正、非複製を個別に確認します。承認時だけ問題、承認済み`tests`概念エッジ、`direct`診断リンクを一括作成し、学習者向け検索・推薦・学習計画・診断充足率へ反映します。承認後の問題は一般編集APIから変更できず、制作ワークフローの監査対象として保持します。第三者問題のURLや本文を原創性メモへ持ち込みません。

問題内容の正しさは、内容承認と分離した独立検証で担保します。作成者は独立再計算、境界条件または反例、誤概念トラップ、解答形式の適合について、再現可能な手順と期待値を問題revisionごとに固定します。作成者・提出者とは異なるreviewer / adminが各手順を実行し、観測結果と合否を検証履歴へ保存します。一件でも不合格なら問題は理由付きで差し戻し、内容指紋を解除します。全件合格後も、検証者自身は最終承認できません。別のreviewer / adminが仕様との一致、採点較正、非複製を確認した場合だけ問題化します。合格率は20件未満では表示せず、小標本を品質改善と誤認しません。

承認後のオリジナル問題は、内容が正しいだけでなく実際に受験者を識別できるかを継続監視します。問題ごとに一人一件の最新答案だけを用い、同じ概念を測る別問題の過去180日間の事前成績をアンカーとして、平均得点、得点分散、設計難度からのずれ、識別相関を集約します。一次判定は30人かつアンカーを持つ20人から、停止候補は100人かつアンカーを持つ60人からに限定します。問題ポートフォリオの仮説判定は判定可能な問題が5問に達するまで保留します。停止候補はreviewer / adminへの調査材料であり、問題の自動停止・自動廃止や個人別結果の表示には使いません。

サービス内で制作したオリジナル問題の答案は、承認直後から学習履歴と実証的妥当性の観測へ保存しますが、校正前の結果を個人の習熟度へ反映しません。30人・アンカー20人以上で設計難度、得点分散、識別相関が健全となったスナップショットについて、reviewer / admin が根拠付きで反映可否を提案し、提案者と異なるadminが承認した場合だけ、新しい答案を習熟度の証拠に使います。承認は問題revisionと観測スナップショットへ固定し、90日で失効します。問題改訂、観測更新、期限切れ、小標本、要監視、停止候補は反映を既定で無効にします。既存の大学公式過去問にはこのオリジナル問題向け校正ゲートを適用しません。

習熟度の難度補正候補は、現行の個人推定を変更しないシャドー比較に限定します。各答案について現行更新後の推定と設計難度の目標得点で補正した候補推定を保存し、同じ人が同じ概念を測る別問題へ1〜30日後に回答した場合だけ、その達成度を将来観測として一件結合します。同一問題の再挑戦、24時間未満の答案、校正ゲートで習熟度反映を停止したオリジナル問題は比較へ入れません。運営指標は50組・5ユーザー以上になるまで誤差を非表示にし、候補が有利でも別途承認するまで習熟度・推薦・計画を変更しません。自由記述、問題文、メールアドレスはシャドー証拠台帳へ複製しません。

本人向けの習熟度根拠画面は、習熟度へ実際に反映した答案について、分野名、問題名、難度、答案証拠、更新前後の推定、日付だけを本人の認証済みセッションへ返します。自由記述、他ユーザー、校正待ちで反映しなかった答案は含めません。同一分野の証拠が3件未満なら一貫性を判定せず、3件以上で得点レンジ60ポイント以上または標準偏差30ポイント以上を「矛盾」、標準偏差20ポイント以上を「揺れあり」とします。矛盾は弱点と同義にせず、別形式・補助なしの確認問題を優先する根拠として扱います。

モデル評価ログ、戦略検証ログ、日程再配分ログ、重点学習ログ、確認枠ログ、確認問題評価ログ、準備度スナップショットの分析対象は直近365日です。再集計のための余裕を含め、400日を超えた評価ログはユーザー単位で自動削除します。学習履歴本体にはこの保持期限を適用しません。

## 第三者コンテンツ

大学が過去問を公開していても、再配布や改変が許可されているとは限りません。取得元へのリンクを保存する場合も、利用条件、著作権表示、公開期間、アクセス制限に従ってください。本リポジトリのMIT Licenseは第三者コンテンツへ適用されません。

本番アプリは第三者のPDFを保存・代理配信しません。問題ページは公式公開元のPDF全体を直接表示または別タブで開き、`page_start` / `page_end` は参照位置の案内にだけ使用します。

既存データの公開移行では、確認済みの大学公式HTTPSホストだけをリンク参照へ昇格します。第三者ミラー、GitHub上の再配布PDF、`restricted`資料は自動公開しません。
